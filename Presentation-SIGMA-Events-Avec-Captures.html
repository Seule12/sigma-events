1. Presentation de SIGMA Events

SIGMA Events est une plateforme complete de gestion evenementielle qui resout trois problemes majeurs dans l'organisation d'evenements en Afrique :

Billetterie en ligne

Creation et vente de billets numeriques avec QR codes cryptes, paiement mobile money, livraison instantanee.

Gestion des invites

Import CSV, envoi automatique WhatsApp/SMS/Email, suivi du cycle de vie complet.

Controle d'entree

Application mobile hors-ligne, zones d'acces, alertes securite temps reel.

Un seul ecosysteme, une seule plateforme. Pas besoin de WhatsApp pour les invitations, Google Sheets pour le suivi, et des papier pour le check-in.

2. Le Probleme

L'Afrique de l'Ouest connait un essor important des evenements. Cependant, les organisateurs font face a des problemes critiques :

Fraude aux billets — Les billets papier sont facilement falsifies. Un meme billet peut etre utilise par plusieurs personnes. Les organisateurs perdent jusqu'a 30% de leurs revenus.
Controle d'entree chaotique — Files d'attente interminables, listes manuelles, erreurs humaines. Pas de visibilite en temps reel.
Pas de suivi des invites — Les organisateurs n'ont aucune visibilite sur qui a recu l'invitation, qui l'a ouverte, qui est entre.
Outils fragmentes — WhatsApp pour les invitations, Google Sheets pour le suivi, des papier pour le check-in. Rien n'est connecte.
SIGMA Events reunifie tout dans une seule plateforme accessible depuis un telephone portable.

3. Notre Solution

Module 1 : SIGMA Events (Web Application)

Application web responsive pour les organisateurs et les clients.

Cote Organisateur :

  • Creation d'evenements en 2 minutes
  • Billets avec QR codes cryptes (AES-256-GCM)
  • Import CSV de milliers d'invites
  • Envoi automatique WhatsApp/SMS/Email
  • Dashboard avec stats en temps reel (Ably)
  • Gestion des agents et terminaux de scan
  • Retrait des fonds via Mobile Money (FedaPay)
  • Command Center de securite (SIGMA Alert)

Cote Client (Billetterie Publique) :

  • Page de vente attractive avec couvertures Unsplash
  • Achat en 3 clics (nom, telephone, paiement)
  • Paiement Mobile Money (MTN, Moov, Celtiis)
  • Livraison instantanee (telechargement / WhatsApp / email)
  • Recuperation du billet par telephone (/mon-billet)
